# Siska — Personal Portfolio

Portfolio website bilingual (Bahasa Indonesia / English), with a soft pastel lavender aesthetic and a spring meadow hero background.

## Files
- `index.html` — page content and sections
- `style.css` — layout, colors, responsive design
- `script.js` — mobile navigation and language switcher
- `assets/spring.jpg` — background image supplied for this project

## Run locally
Open the folder in VS Code and use Live Server on `index.html`, or open `index.html` directly in your browser.

## Before publishing
1. Replace the sample email `emailkamu@example.com` with your professional email.
2. Update GitHub and Behance links to your own profiles.
3. Replace the example project descriptions/statuses with your actual work.
4. Keep the skill descriptions accurate: HTML and CSS are currently in the learning stage.

## Publish with GitHub Pages
1. Create a public repository on GitHub.
2. Upload the contents of this folder (the `index.html` file must be in the repository root).
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/(root)`, then Save.
5. Wait for deployment and open the URL displayed on the Pages settings screen.
