## 📂 Struktur Proyek

Struktur folder dapat disesuaikan dengan file aktual di repository.

```text
portfolio-webdevku/
├── index.html
├── style.css
├── script.js
├── assets/
│   ├── images/
│   └── icons/
└── README.md
```

**Keterangan:**
- `index.html` — halaman utama website.
- `style.css` — aturan desain dan tata letak website.
- `script.js` — logika interaktif jika digunakan.
- `assets/` — tempat menyimpan gambar, ikon, dan aset pendukung.
- `README.md` — dokumentasi proyek.

## 🚀 Cara Menjalankan Proyek

1. Unduh atau kloning repository ini.
2. Buka folder proyek menggunakan Visual Studio Code.
3. Buka file `index.html` melalui browser atau gunakan ekstensi Live Server.
4. Ubah kode HTML dan CSS sesuai kebutuhan.
5. Simpan perubahan dan periksa hasilnya di browser.

Untuk melihat website tanpa mengunduh kode, kunjungi tautan GitHub Pages yang tersedia di atas.
